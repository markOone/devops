## 2. Документація по розробленому веб-застосунку
**Призначення застосунку:**
Task Tracker — простий сервіс для відстеження задач (id, title, status, created_at). Застосунок написано на Python з використанням фреймворку Flask.

**Налаштування середовища та запуск:**
Застосунок розроблено для запуску на Linux-серверах за допомогою Gunicorn та Systemd Socket Activation.
1. Встановити залежності: `pip install -r requirements.txt`.
2. Створити конфігураційний файл `/etc/mywebapp/config.json` із доступами до БД.
3. Виконати міграцію: `python3 init_db.py`.
4. Запустити локально (для розробки): `python3 app.py` (на порту 3000).

**API Ендпоінти:**
* `GET /health/alive` — перевірка стану (завжди повертає 200 OK).
* `GET /health/ready` — перевірка підключення до БД (200 OK або 500).
* `GET /` (Тільки HTML) — список усіх ендпоінтів застосунку.
* `GET /tasks` — вивести усі задачі. Підтримує заголовок `Accept: application/json` та `Accept: text/html`.
* `POST /tasks` (тіло: `title`) — створити нову задачу.
* `POST /tasks/<id>/done` — змінити статус задачі на "done".
